# モデルルーティング（opencode-model-router）

better-opencode は [opencode-model-router](https://github.com/marco-jardim/opencode-model-router) を既定の外部プラグインとして読み込みます。タスクを fast / medium / heavy の階層に振り分け、安いモデルで足りる作業に高いモデルを使わないようにします。

## 既定の動作

- 設定でこのパッケージに言及していない場合、CLI が起動するサーバーは `opencode-model-router@latest` を既定のプラグインとして追加します。
- 初回起動時に npm から取得し、プラグイン用キャッシュへ保存します。オフラインで取得できない場合は、その他のプラグインと同様に読み込み失敗として扱われ、セッション自体は続行します。
- `@latest` は既存のプラグイン更新機構の対象です。24 時間ごとに新しい版を確認し、あれば自動でインストールして再読み込みします。
- プラグインが提供する TUI のステータス行も、サーバー側のプラグイン一覧から自動で読み込まれます。

ルーティング先のモデルや予算モードはプラグイン側の設定です。まず `/preset` で利用中のプロバイダーに合わせ、`/budget` で方針を選んでください。詳細はプラグインの README と `~/.config/opencode/opencode-model-router.overrides.jsonc` を参照してください。

## 無効化・バージョン固定

グローバルまたはプロジェクトの `opencode.json` / `opencode.jsonc` で上書きできます。

```jsonc
{
  "plugins": ["-opencode-model-router"],
}
```

既定の `@latest` を残したまま自動更新だけを止めたい場合は、バージョンを固定します。

```jsonc
{
  "plugins": ["opencode-model-router@2.9.1"],
}
```

バージョンを付けない `"opencode-model-router"` も既定の `@latest` を置き換えます。この場合はインストール済みの版がそのまま使われ、自動更新の対象にはなりません。`"-*"` はすべてのプラグイン除去なので、既定プラグインもインストールされません。

設定の操作は優先順位の高いファイルが最後に適用されます。既定の読み込みは最も低い優先順位なので、上記のいずれでも無効化・置き換えができます。

自動化や隔離されたテストで既定プラグイン自体を止めたい場合は、CLI のサーバープロセスに `OPENCODE_DISABLE_DEFAULT_PLUGINS=1` を渡します。この環境変数は設定ファイルより優先され、既定の追加だけを止めます。

## ライセンスと配布

- `opencode-model-router` は **GPL-3.0-only**、better-opencode は **MIT** です。
- better-opencode はプラグインのコードを同梱・ベンダー・リンクしていません。リポジトリとリリース物に含まれるのは、npm パッケージを指す既定設定だけです。実際のコードは利用者のマシンが npm から取得し、配布主体はパッケージの公開者です。
- したがって、この既定設定自体は GPL コードの再配布には当たらないという整理です。ただし、リリース物へパッケージを同梱する、`package.json` の依存に加えてバンドルする、ソースを取り込むといった変更をすると、GPL の結合著作物・再配布の検討が必要になります。その場合は法務確認なしに既定搭載へ戻さないでください。
- 利用者がインストール済みプラグインを再配布する場合は、プラグイン側の GPL-3.0 条件が適用されます。
- これは実装上の整理であり、法的助言ではありません。配布方法を変える場合は法務に確認してください。

## 供給網の注意

自動更新は第三者が公開する npm パッケージを定期的に取得して実行します。固定バージョンにするか、`"-opencode-model-router"` で無効化すると、この自動更新を止められます。組織で配布する場合は、固定バージョンとレビュー済みの更新を推奨します。
